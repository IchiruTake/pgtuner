## [0.1.3]

Date of Release: 2025-02-16

Programming Language: Python 3.12+

Author: Ichiru Pham

This is the third minor release of the pgtuner project. Nothing new here, just end up with cleanup and maintenance. 

### Highlights

Backend: 

- Update the formula for `bgwriter` and `autovacuum` parameters to improve performance.

Frontend:

- Break down the large `tuner.html` and `changelog.html` templates into smaller templates for better maintainability.
- Remove RAID configuration for disk parameters to simplify the UI.
- Add `vacuum_safety_level` parameter into the tuning guideline to enhance database maintenance.
- Remove the `os_reserved_memory` parameter to streamline the configuration.
- Switch the default disk performance from `SSDv1` to `SANv1` to reflect the current best practices.
- Add `rjsmin` as the minifier for the JS file to improve performance.
- Fix the `README.md` file to ensure it is up-to-date and accurate.
