## [0.1.6]

Date of Release: 2025-07-14

Programming Language: Python 3.12+ & Native HTML/CSS/JS

Author: Ichiru Pham

Co-authors:

- Pham Hoang Phuong: He is the main author of the new UI interface based on the previous UI (Jinja2) template along with the `v0.dev` AI.


This is the large release but under the "patched" version. You would have a new UI interface and a dedicated feature for profile auto-calibration.


### Highlights

- New UI interface changed from Bootstrap CSS to Tailwind CSS.
- Minor configuration changes, focusing on the higher memory utilization and parallelism.
- New features: Profile auto-calibration based on the workload type.


#### Input Changes

| Configuration                 | Type     | Old Value     | New Value                   | Explanation                                                                                                                                                                                                     |
|-------------------------------|----------|---------------|-----------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `hash_mem_usage_level`        | Default  | -5 (1.1417)   | -5 (1.2114)                 | More consulting experience bump the usage of HASH-query execution plan                                                                                                                                          |
| `max_normal_memory_usage`     | Default  | 0.45          | 0.55                        | Increase the memory usage by default                                                                                                                                                                            |
| `max_work_buffer_ratio`       | Default  | 0.075         | 0.125                       | Increase the work buffer ratio by default                                                                                                                                                                       |
| `cpu_to_parallel_scale_ratio` | Advanced | NOT AVAILABLE | 2.0 (range from [1.5, 3.0]) | Revise the use of parallel workers with better algorithm. This impact the `max_worker_processes`, `max_parallel_workers`, `max_parallel_workers_per_gather`, and `max_parallel_maintenance_workers` parameters. |

#### Algorithm Changes

| Parameter                         | Old Logic                 | New Logic                                                |
|-----------------------------------|---------------------------|----------------------------------------------------------|

- *_BKE: The background writer during correction tuning write 10 more pages per workload sizing, and has 50 millisecond delay extra between cycles
- *_BKE: Enforce the number of user connections to be a multiple of 5 for human quick calculation
- *_BKE: Create an 'auto' option for automatic profile calibration that based on the workload type.

Others:
- JS_BKE: The `backend_flush_after` fix the missing of casting function
- *_BKE: Fix several other issues
