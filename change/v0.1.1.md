## [0.1.1]

Date of Release: 2025-02-09

Programming Language: Python 3.12+

This is the first patch release of the `pgtuner` project, focusing on code cleanup, performance improvements, and minor feature enhancements. It is a follow-up to the initial release, ensuring that the project remains maintainable and efficient.

### Highlights

- Cleanup development and legacy code
- Better performance on correction tuning phase, especially on the memory pool increase tuning task, fasten from 6 ms to 1-2 ms
- Create robots.txt file for web crawler to index the web page
- Move `_version` endpoint to the `_health` endpoint with a more dedicated health check; service uptime is reported
- Prepare CHANGELOG file for future release
- Refactor the rate-limit middleware: Merge the global rate-limit and the user rate-limit into one middleware
