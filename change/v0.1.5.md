## [0.1.5]

Date of Release: 2025-05-13

Programming Language: Python 3.12+ & Native HTML/CSS/JS 

Author: Ichiru Pham

This is the large release but under the "patched" version. A lot of thing news, including the re-calibration of all parameters and the introduction of the native client-side web applications (port from FastAPI/Jinja2 to HTML/CSS/JS-native). The default parameters (without correction tuning) are now more suitable across workload type, even for the small system. We also introduce the support for PostgreSQL 18. 

### Highlights

- Native client-side web app (HTML/CSS/JS) replacing FastAPI/Jinja2, improving performance and reducing complexity.
- Adding support for PostgreSQL 18. 
- Algorithm improvements: More adaptive tuning for parallelism, background writer, and timeouts; better workload-based configuration. New and revised tuning parameters for memory, connections, and WAL sizing, including reverting wal_segment_size upper bound to 2 GiB.

* Remove:
  * All `*_profile` parameters except the `workload_profile` parameter.
  * Parameters of the OS and DB Log disk.
  * Workload of SOLTP, LOG, DW in :enum:`PG_WORKLOAD`.
  * Enumeration the backup tool from string to :enum:`PG_BACKUP_TOOL`.
  * Supported operating system is 'linux', 'windows', 'macos', 'containerd', and 'PaaS'.
